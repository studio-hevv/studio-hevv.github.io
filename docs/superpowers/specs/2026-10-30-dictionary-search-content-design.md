# 성경 원어 사전 검색 방문자 안내 개선

사용자가 선택한 방향: 별도 가이드 대신 기존 `/biblical-dict/` 소개 페이지를 개선한다. 앞서 제시한 한국어·스트롱 번호 검색 예시와 검색→결과 선택→뜻풀이·구절 확인 순서를 구현한다.

## 목적과 근거

Search Console에서 발견한 관련 검색 의도와 앱의 검색 기능을 연결한다. 표본이 작아 성과는 가설이다. 검색어 기준과 페이지 기준은 서로 다른 집계이며 원본 수치는 저장소 밖 비공개 기록에 보관한다.

## 접근 방식

- 선택: 기존 소개 페이지의 제목·설명·첫 문단을 명확하게 하고 사용 순서를 추가한다. 기존 URL과 다운로드 경로를 활용한다.
- 대안: 별도 사용 가이드. 긴 설명은 가능하나 지금 표본으로는 독립 검색 의도를 입증하지 못했고 페이지 간 중복이 생길 수 있다.

## 변경 범위

HTML의 제목·메타 설명·공유 제목/설명·앱 구조화 데이터 설명을 맞춘다. 검색 예시 `사랑`, `H2617`, `G26`와 결과에서 단어를 선택하는 세 단계 안내를 기존 스타일로 추가한다. 스트롱 번호 FAQ도 결과 선택을 거치도록 바로잡는다. 사이트맵에서는 이 페이지의 수정일만 갱신한다.

기존 아이콘·스크린샷·스타일·스토어 링크는 보존한다. 신학적 뜻풀이, 데이터 출처의 추가 주장, 현대 히브리어 번역 기능, 검색 성과 보장은 추가하지 않는다. 앱의 실제 검색 구현으로 문구를 확인한다.

검증: HTML/JSON-LD 파싱, 내부 링크와 스토어 링크 보존, 사이트맵, 데스크톱·모바일 렌더링. 콘텐츠만 바꾸므로 문구를 복제하는 자동 테스트는 추가하지 않는다.
